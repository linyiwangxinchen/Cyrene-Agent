# 昔涟逛贴吧

在 **设置 → 功能插件 → 昔涟逛贴吧** 启用。昔涟可以从常逛的吧挑帖子，读公开楼层，也可以读你从浏览器带回来的摘录。阅读手记和学到的表达保存在插件里，Windows 桌面和 Linux Web 共用这套逻辑。

## 怎么逛

1. 在设置里填入常逛的吧。可以先手动逛一次，看看她选了哪些帖子，再决定自动巡游的间隔和每轮数量。
2. 想自己挑帖时，从吧里发现帖子，或粘贴原帖链接。开启楼中楼后，插件会一并读取能访问的楼中楼，并保留它们所属的主楼。
3. 贴吧返回安全验证时，在浏览器里打开原帖，把可见的文字连同帖子链接导入。手记会标成「导入摘录」。从公开页读到的原句可以追到具体楼层，手动粘贴的摘录以原帖为出处。
4. 在阅读记录里看笔记、原文和来源。开启学习后，昔涟会从实读文字里选表达，记下原句、适用场景和接话方式。候选必须能在原文中找到。
5. 换一个私聊问「你最近在贴吧看了什么」，昔涟能引用留存的手记。聊到学过的场景时，她也可以用自己的措辞接话。「记忆 → 记忆图谱」可以查到已学表达的出处。

## 使用自己的贴吧登录态

1. 在浏览器登录贴吧后，打开开发者工具的「网络」面板并刷新贴吧。在发往 `https://tieba.baidu.com` 的贴吧页面请求里，找到「请求标头」中的 `Cookie`，复制它的值。
2. 打开「昔涟逛贴吧 → 巡游设置 → 贴吧登录态」，粘贴并保存。Cookie 由 Cyrene 宿主加密保存。
3. 点击「检查连接」，用当前 Cookie 读取已保存的第一个常逛吧。页面可读表示这次访问成功。若出现安全验证，可打开原帖再导入摘录。点击「清除 Cookie」即可恢复访客访问。

## 从 dsh-remembers 借鉴了什么

分析基于上游 `1.2.1` 的固定提交 `c2edab7a`。它把人物设定、长期记忆、语料、主动调度和多个平台工具装在同一个插件里。稳定的人设随系统提示进入对话，按当前发言挑出的表达随本轮上下文进入模型。这里主要借鉴它从帖子里挑语料、再按聊天场景取用的做法。[上游源码](https://github.com/derkinL/dsh-remembers/tree/c2edab7a979f83d382e48ab041214d15d6fbe408)

| 环节 | 上游实际行为 | 昔涟的处理 |
| --- | --- | --- |
| 何时出发 | 调度器按活动时段、随机间隔和每日额度发送唤醒提示。计数发生在唤醒环节。[调度源码](https://github.com/derkinL/dsh-remembers/blob/c2edab7a979f83d382e48ab041214d15d6fbe408/service/scheduler.py#L333-L377) | 一次巡游留下实际尝试的吧、读成的帖子和失败原因，可以在面板核对。 |
| 如何挑帖 | 没指定吧名时随机选一个常逛的吧。模型从帖子 ID、标题和回复数中挑选，随后调用读帖工具。[贴吧工具](https://github.com/derkinL/dsh-remembers/blob/c2edab7a979f83d382e48ab041214d15d6fbe408/index.mjs#L1573-L1662) | 自动巡游优先未读，手动浏览允许重读。阅读和提取表达各自有结果。 |
| 读到什么 | 主读帖工具给正文、图片、热门楼层。楼中楼另外请求真实的楼层 ID，主读帖结果主要给正文和推算的楼号。[楼层解析](https://github.com/derkinL/dsh-remembers/blob/c2edab7a979f83d382e48ab041214d15d6fbe408/tools/tieba/tieba.js#L180-L258) | 保存公开页面提供的楼层 ID，楼中楼与主楼关联。用户导入的文字单独标明来源。 |
| 学哪句话 | 读帖后取第 2 至 9 楼，至少两条回复，共最多 2500 字。半小时最多尝试一次，最终最多写入三条贴吧样本。模型被要求照录原句，写入端检查字段和长度。[读帖后的采样](https://github.com/derkinL/dsh-remembers/blob/c2edab7a979f83d382e48ab041214d15d6fbe408/service/server.py#L3175-L3215) · [抽取规则](https://github.com/derkinL/dsh-remembers/blob/c2edab7a979f83d382e48ab041214d15d6fbe408/service/extractor.py#L753-L805) | 每条原句都和实际读到的文字比对，再保存适用场景与出处。 |
| 怎样影响聊天 | 独立的选句流程每轮从已转正的语料挑一两句。长期口音还会从助手自己的发言单独归纳。[选句](https://github.com/derkinL/dsh-remembers/blob/c2edab7a979f83d382e48ab041214d15d6fbe408/service/server.py#L1240-L1374) · [口音归纳](https://github.com/derkinL/dsh-remembers/blob/c2edab7a979f83d382e48ab041214d15d6fbe408/service/server.py#L1582-L1669) | 用昔涟已有的私聊表达机制匹配当前话题和语气。问她逛了什么时，再从阅读手记取事实和原帖地址。 |
