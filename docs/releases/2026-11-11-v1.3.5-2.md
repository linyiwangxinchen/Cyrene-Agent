5. 从 NSIS 安装器提取的 `Cyrene.exe` 和 `resources/app.asar` 与 `win-unpacked` 对应文件的 SHA-256 一致。

## 可复现的打包运行检查

在完成桌面构建和打包后执行：

```powershell
node scripts/verify/installer-validation.mjs
node scripts/verify/installer-artifacts.mjs --expect-version 1.3.5-2 --config electron-builder.fork.yml
node scripts/verify/windows-packaged.mjs release/win-unpacked
```

`windows-packaged.mjs` 在临时目录创建独立用户数据与 Windows 已知目录，通过调试入口运行未经修改的发行 ASAR。为避免影响正在使用的桌面环境，测试启动器抑制登录项写入、全局快捷键注册和可见窗口，并阻止数据库 Worker 继承测试专用的 `--inspect-brk` 暂停参数；数据库 Worker 本身实际运行。日志、界面截图与检查结果留在脚本输出的临时目录。

这不是完整安装/卸载验收，未验证系统登录项或全局快捷键。本次未连接真实账号、模型供应商、远端 Linux 或线上 Cloudflare Tunnel；此前共享内核构造模型与 Web 界面验收见翁法罗斯二期实现文档。
