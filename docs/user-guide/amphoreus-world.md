# 翁法罗斯世界

在设置侧栏打开 **翁法罗斯**，它与“昔涟设置”并列。这里展示世界动态、重大事件、持续公共事务、居民经历、城邦状态、世界编年史、昔涟日记和设定来源。

## 世界从哪里开始

历史基线是官方翁法罗斯篇对抗**铁墓**之后。官方结局没有直接确认所有人在重建城市中继续生活，因此本功能以保存的世界记忆为起点，运行明确标注的**战后延续世界线**。官方人物与经历是约束；每日事件是本项目续写，不是官方后续任务。

居民包含十二黄金裔（缇宝、缇安、缇宁合计一席）、昔涟，以及哈托努斯、德墨忒尔、阿芙罗、尼刻、利波、达利安。昔涟最多参与每日一个公共事件，其他居民有自己的目标与生活。三子分别保存目标和经历，共享黄金裔席位，共 21 位独立居民。人物卡可查看资料来源。

## 时间与模型

- 时间使用用户资料中的时区，与现实日期、昼夜同步。每个人都有早餐、午餐、晚餐、休息和睡眠；没有公共事件时仍按日程活动。
- 默认启用“每日世界续写”，复用模型设置中的默认模型档案。须先填好模型和 API Key；缺少配置时只运行本地作息。
- 每天最多一份成功计划，包含 3–8 件公共事件，至少涉及 6 位居民、2 个地点与一位 NPC。活动结束后批量结算，可能完成、部分完成或失败。默认每日最多 8 次模型请求，规划、结算和重大结果审核共用额度；每个任务最多尝试 3 次，失败退避 30 分钟，单次流程超时 90 秒。页面可查看状态和调用次数。
- 公共事务随实际结果延续。物资、设施、通路、个人目标与关系的变化会影响后续安排；前序事件失败、物资不足或需要休息时，活动可以延期或取消。计划不携带预写的结果。较晚启动时，今日早先时段属于模拟补叙，停机多日不会逐日追发请求。
- 关闭每日续写只停止模型推进，居民作息仍运行。打开/刷新页面不会额外调用模型。
- 世界后台与主动聊天、QQ/微信渠道开关独立。桌面程序或 Linux 服务需要运行；关机期间不会有实际后台调用。恢复时记录离线区间，按有界作息恢复状态，并处理未结事项；不会为每个停机日逐日调用模型补故事。

聊天与自拍使用同一份世界状态。昔涟亲历的结果立即形成经历；公开消息至少经过两小时，并在吃饭或交谈等时段被听闻，记录消息来源。私人事件不向所有居民传播，已经听过的消息不会因短期记忆压缩被反复当成新闻。普通聊天、主动消息与生活自拍共用她的状态，不使用观察页的全知视角。世界日记不写入用户现实关系事实。

## 旧数据与兼容

程序首次使用世界时，把用户数据目录中的 `xilian-world.json` 复制迁移到 `amphoreus-world.json`。旧原件保留，日记、事件 ID、自拍绑定不删除。旧架空地点只留在历史，新日程使用翁法罗斯地点。

新文件外层采用 version 3，内层世界 schema 2；首次升级 schema 1 时额外保留 `.schema1-backup.json`。已完成事实和事件 ID 保留，旧版预写的未来结果不继续作为事实使用。

完整快照先原子写入，再将事件、个人经历、事务版本和离线区间幂等归档到 `amphoreus-history.sqlite`。归档成功后，快照保留最近 60 天及仍未完成的计划、每人最近 48 段记忆；未结事务不按条数删除。个人兼容时间线和日记仍保留最近 2000 条，旧涟界原文件继续保留。长期世界历史通过编年史分页读取；一次默认 30 条，最多 80 条。

备份前停止应用/服务，备份整个用户数据目录，至少包含两个世界 JSON、schema 1 原件备份、`amphoreus-history.sqlite` 及存在时的 `-wal`、`-shm` 文件，还有原图片目录。若出现损坏，程序先保留 `.corrupt-*.json`；未知未来版本拒绝覆盖。归档失败时完整快照仍保留，不会先删掉尚未归档的历史。

## 如何观察变化

- **世界动态**：展开“缘由与后续”，查看原意图、前提、延期原因、实际结果和留下的影响。
- **居民**：查看当前活动、正在惦记的事、目标、关系变化依据，以及亲历、听闻和日常记录；可进入该人的完整历史。
- **地点**：轻量示意图显示十处地点及通路。选择地点可看当地人物、物资、设施和事件。路线及行程时间属于项目模拟，不是官方地理尺度。
- **世界编年史**：按人物和地点筛选，分页加载更早记录。事件归档后仍保留原意图、前提和影响，便于追溯因果。
- **上次离开之后**：按此浏览器的上次访问时间过滤变化；无本地存储时不显示这个入口。
- **昔涟的生活**：查看个人日记及已生成的画面。图片点击后才加载；仅允许读取已绑定、位于应用数据目录内的 PNG/JPEG/WebP，单张不超过 8 MiB。缺失或旧路径作品保留记录并提示无法预览。

Linux/Web 使用共享核心，与桌面行为一致。Web 页面隐藏时停止轮询，返回时刷新。刷新携带内容标识，数据未变化时只返回时钟，避免反复传输全部静态资料和历史；居民活动、生成状态或作品变化仍会触发更新。手机端布局适配窄屏；通过 CF Tunnel 访问时，该页面只在打开后加载。

## 开发与验证

[资料与设计文档](../design/2026-11-10-翁法罗斯世界线重构.md) 包含时间线边界与资料索引；[二期实施设计](../design/2026-11-10-翁法罗斯二期实施设计.md) 说明持续状态、事件结算、归档与成本边界。

在 Node.js 24、pnpm 10.33.0 环境下：

```bash
corepack pnpm exec vitest run src/main/amphoreus-world src/main/xilian-world src/renderer/react/features/settings/AmphoreusWorldPanel.test.tsx
corepack pnpm run check:main
corepack pnpm run check:preload
corepack pnpm run check:renderer
corepack pnpm run check:server
corepack pnpm run build:server
corepack pnpm run build:renderer
node scripts/verify/amphoreus-world.mjs
# 可选：已安装 Playwright Chromium 时验证桌面与手机页面
node scripts/verify/amphoreus-world.mjs --ui
```

接口验证创建独立临时数据目录和测试模型，禁用所有渠道，验证关闭主动聊天时仍自动推进、重启不重复请求、配置校验和页面展示，不使用个人账号或现有世界数据。它验证协议与运行链路，不证明任意真实模型都能稳定生成合格的剧情。
