# 翁法罗斯世界

在设置侧栏打开 **翁法罗斯**，它与“昔涟设置”并列。这里展示世界动态、重大事件、持续公共事务、居民经历、城邦状态、世界编年史、昔涟日记和设定来源。

## 世界从哪里开始

历史基线是官方翁法罗斯篇对抗**铁墓**之后。官方结局没有直接确认所有人在重建城市中继续生活，因此本功能以保存的世界记忆为起点，运行明确标注的**战后延续世界线**。官方人物与经历是约束；每日事件是本项目续写，不是官方后续任务。

居民包含十二黄金裔（缇宝、缇安、缇宁合计一席）、昔涟，以及哈托努斯、德墨忒尔、阿芙罗、尼刻、利波、达利安。昔涟最多参与每日一个公共事件，其他居民有自己的目标与生活。三子分别保存目标和经历，共享黄金裔席位，共 21 位独立居民。人物卡可查看资料来源。

## 时间与模型

- 时间使用用户资料中的时区，与现实日期、昼夜同步。每个人都有早餐、午餐、晚餐、休息和睡眠；没有公共事件时仍按日程活动。
- 默认启用“每日世界续写”，复用模型设置中的默认模型档案。须先填好模型和 API Key；缺少配置时只运行本地作息。
- 每天最多一份成功计划，包含 3–8 件公共事件，至少涉及 6 位居民、2 个地点与一位 NPC。活动结束后批量结算，可能完成、部分完成或失败。默认每日最多 8 次模型请求，规划、结算和重大结果审核共用额度；每个任务最多自动尝试 3 次，失败退避至少 30 分钟。每次请求最多等待 180 秒，结算和审核分别计时。页面可查看状态和调用次数。
- 公共事务随实际结果延续。物资、设施、通路、个人目标与关系的变化会影响后续安排；前序事件失败、物资不足或需要休息时，活动可以延期或取消。计划不携带预写的结果。较晚启动时，今日早先时段属于模拟补叙，停机多日不会逐日追发请求。
- 关闭每日续写只停止模型推进，居民作息仍运行。打开/刷新页面不会额外调用模型。
- 世界后台与主动聊天、QQ/微信渠道开关独立。桌面程序或 Linux 服务需要运行；关机期间不会有实际后台调用。恢复时记录离线区间，按有界作息恢复状态，并处理未结事项；不会为每个停机日逐日调用模型补故事。

聊天与自拍使用同一份世界状态。昔涟亲历的结果立即形成经历；公开消息至少经过两小时，并在吃饭或交谈等时段被听闻，记录消息来源。私人事件不向所有居民传播，已经听过的消息不会因短期记忆压缩被反复当成新闻。普通聊天、主动消息与生活自拍共用她的状态，不使用观察页的全知视角。世界日记不写入用户现实关系事实。

## 续写失败后如何恢复

“本项尝试 3 次”和“今日世界推演 3/8”分别表示单项自动尝试次数与当天全部模型请求。达到自动上限后，当天不会自动重试该项，页面会明确提示；本地吃饭、休息和个人生活仍然运行。

先根据页面的失败原因检查超时、限流、凭据、额度或模型设置。仍有每日额度时，可点击“重试续写”手动发起一次请求；它沿用同一个任务并继续累计次数，不清空失败历史和已用额度。连续操作至少间隔一分钟，限流时还需等待服务商规定的冷却时间。重复点击和刷新页面不会重复发请求。每日总额度用完后，只能等待下一当地日期；重大结果还需要为审核保留一次调用。

旧记录没有保存详细原因时，会显示“具体原因尚未确定”，不会把它推断成网络或凭据错误。新记录只保存分类及 HTTP 状态，不保存服务商错误正文、密钥和地址。停止服务、关闭续写、跨日或更改时区时，迟到的模型结果仍会被丢弃。

## 昔涟的生活与主动分享

昔涟在公共活动之外，有自己的个人行动与持续项目。计划只表示准备做什么；行动实际结束后，才能留下经历、阶段进展或轻量作品。休息需求、公共约定、通行和时区变化可以中断安排。其他居民的目标也由实际行动推进，公共事务保留阶段、阻碍和依据。

每日模型规划可以顺带提出最多三项个人行动意图，不增加请求次数。没有模型时，本地规则仍会安排记录、练习等轻量活动；复杂剧情继续通过已有公共事件规划与结算，不能把规则生成的小记录视为任意复杂故事的模拟。

在**偏好设置 → 主动聊天**中选择安静、自然或活跃的分享意愿。活跃表示有具体内容时更愿意分享；每日开场上限仍是上限，程序不会为了凑够数量发送消息。升级保留原来的开关、日上限、渠道和安静时段，未配置密度时使用活跃。

主动消息会来自已知见闻、自己的进展、与明确聊天话题相关的联想、有生活依据的无聊，以及用户指定的跟进事项。聊天结束半小时、早晨或晚上到点，本身不会自动产生消息。三分钟防连发和滚动一小时最多四次只控制打扰，不代表每隔这段时间一定发送。

她可以把念头留着，等用户回来或事情有新进展；重复、过时的内容会放下。未回复一次后明显收敛，第二次只允许新的、无需回复的独立内容；连续两次未回复后停止主动开场。每天最多三次提问类开场。明确预约的提醒继续使用原来的提醒机制。

暂停、安静时段、断线和停机不会积累“欠下的消息”。重启沿用原机会及来源去重记录，不重新抽取时机，也不批量补发旧小记。私人会话中的原话和带会话范围的建议只在原会话使用，群聊及插件代理不注入私人生活上下文。

## 旧数据与兼容

程序首次使用世界时，把用户数据目录中的 `xilian-world.json` 复制迁移到 `amphoreus-world.json`。旧原件保留，日记、事件 ID、自拍绑定不删除。旧架空地点只留在历史，新日程使用翁法罗斯地点。

新文件外层采用 version 3，内层世界 schema 3；升级时保留对应的 schema 1/2 原件备份。已完成事实和事件 ID 保留，旧版预写的未来结果不继续作为事实使用。

完整快照先原子写入，再将事件、个人经历、事务版本和离线区间幂等归档到 `amphoreus-history.sqlite`。归档成功后，快照保留最近 60 天及仍未完成的计划、每人最近 48 段记忆；未结事务不按条数删除。个人兼容时间线和日记仍保留最近 2000 条，旧涟界原文件继续保留。长期世界历史通过编年史分页读取；一次默认 30 条，最多 80 条。

世界的个人获知变化与结果一并提交，短期保留十四天、最多 2000 条，供主动分享读取；首次升级不把旧历史全当作新见闻。主动机会另存于 `initiative-opportunities.json`，保存起意时机、暂存念头、去重及待复核的投递记录。

备份前停止应用/服务，备份整个用户数据目录，至少包含两个世界 JSON、已有 schema 原件备份、`amphoreus-history.sqlite` 及存在时的 `-wal`、`-shm` 文件、`companion-life.json`、`initiative-opportunities.json`、`proactive-state.json`，还有原图片目录。若出现损坏，世界程序先保留 `.corrupt-*.json`；未知未来版本拒绝覆盖。归档失败时完整快照仍保留，不会先删掉尚未归档的历史。主动机会文件损坏或版本未知时停止读取，不覆盖投递去重记录。

## 如何观察变化

- **世界动态**：展开“缘由与后续”，查看原意图、前提、延期原因、实际结果和留下的影响。
- **居民**：查看当前活动、正在惦记的事、目标、关系变化依据，以及亲历、听闻和日常记录；可进入该人的完整历史。
- **地点**：轻量示意图显示十处地点及通路。选择地点可看当地人物、物资、设施和事件。路线及行程时间属于项目模拟，不是官方地理尺度。
- **世界编年史**：按人物和地点筛选，分页加载更早记录。事件归档后仍保留原意图、前提和影响，便于追溯因果。
- **上次离开之后**：按此浏览器的上次访问时间过滤变化；无本地存储时不显示这个入口。
- **昔涟的生活**：查看她正在做什么、惦记的事、小项目、个人经历和行动状态；可进入个人历史。计划不展示尚未发生的结果。原个人日记及已生成的画面继续保留；图片点击后才加载，仅允许读取已绑定、位于应用数据目录内的 PNG/JPEG/WebP，单张不超过 8 MiB。缺失或旧路径作品保留记录并提示无法预览。

Linux/Web 使用共享核心，与桌面行为一致。Web 页面隐藏时停止轮询，返回时刷新。刷新携带内容标识，数据未变化时只返回时钟，避免反复传输全部静态资料和历史；居民活动、生成状态或作品变化仍会触发更新。手机端布局适配窄屏；通过 CF Tunnel 访问时，该页面只在打开后加载。

```bash
corepack pnpm exec vitest run src/main/amphoreus-world src/main/xilian-world src/renderer/react/features/settings/AmphoreusWorldPanel.test.tsx
corepack pnpm exec vitest run src/main/proactive src/main/orchestrator/agent-runtime.test.ts src/renderer/react/features/settings/PreferencesSettingsPanel.test.tsx
corepack pnpm run check:main
corepack pnpm run check:preload
corepack pnpm run check:renderer
corepack pnpm run check:server
corepack pnpm run build:server
corepack pnpm run build:renderer
node scripts/verify/amphoreus-world.mjs
# 可选：已安装 Playwright Chromium 时验证桌面与手机页面
node scripts/verify/amphoreus-world.mjs --ui
node scripts/verify/proactive-rhythm.mjs
```

接口验证创建独立临时数据目录和测试模型，禁用所有渠道，验证关闭主动聊天时仍自动推进、重启不重复请求、配置校验和页面展示，不使用个人账号或现有世界数据。它验证协议与运行链路，不证明任意真实模型都能稳定生成合格的剧情。
