# 主动关心与翁法罗斯三期实施与验收

日期：2026-11-17。对应[三期设计](2026-11-17-主动关心与翁法罗斯三期设计.md)。实施目录为 `Cyrene-Agent-github`，未涉及 NapCat。

## 实际行为

主动开场现在由具体来源驱动：昔涟已知的世界见闻、个人行动结果、生活中的无聊、与真实聊天话题相关的联想、明确跟进事项和已启用插件的内容。生产链路关闭了常驻白天候选和纯时间场景；聊天结束满半小时本身不产生消息。

每个机会以来源、事件、证据版本和会话范围去重。机会只抽取一次起意阈值，在允许开口的时间里积累意愿；重启保留阈值。见闻、兴趣联想等随来源年龄衰减，有些念头会自然过期，不承诺每件事最终都会发送。模型可以选择发送、暂存或放下，暂存不能靠固定计时反复重问。

安静、自然、活跃三档调整分享意愿，未配置时使用活跃。升级保留原开关、每日上限、渠道、目标分和安静时段；原每日上限为 3 的用户仍然是 3，可以在偏好设置中提高。上限不构成发送配额。

三分钟防连发、滚动一小时最多四次、每日最多三次提问共同控制打扰。未回复一次后，第二次仅允许新的、独立且无需回复的内容；连续两次未回复后停止主动开场。锁屏、会话占用、暂停、安静时段、断线和停机不累计发送压力。原有预约提醒机制继续处理明确预约。

## 世界与个人生活

翁法罗斯保留 21 位居民的群像推进、公共事件结算和长期编年史，新增昔涟的个人视图：精力、心情、正在做什么、持续项目、行动、个人经历和已获知的变化。界面展示“昔涟的生活”，计划与已发生结果分开呈现。

个人行动经过计划、执行、完成或中断后才形成事实。每日世界规划可顺带提出最多三项个人行动意图，沿用既有模型预算；缺少模型时本地规则也能安排有限的记录、练习等活动。公共计划不能事后覆盖已经发生的私人行动，休息、移动和公共约定可以使个人安排中断。

个人目标的阶段变化由实际行动与结果推动，其他居民的目标也不再靠每日固定加分。持续公共事务保存阶段、阻碍和依据。昔涟只将自己亲历或实际听闻的事情带入聊天；观察页可见的其他居民动态不会自动成为她已知的消息。

世界推进独立于主动消息开关。生成计划、到期结算、迁移、归档与作品访问继续复用桌面和 Web 的共享核心。

## 持久化、恢复与范围

- 世界快照升级到 schema 3，旧 schema 1/2 保存原件备份。完整结果和个人变化先原子提交，再幂等归档，成功后才裁剪短期快照；未知未来版本拒绝覆盖。
- 个人变化短期保留十四天、最多 2000 条；首次升级不会把全部旧历史转换成新的分享机会。长期事件与经历继续进入 `amphoreus-history.sqlite`。
- 新增用户数据文件 `initiative-opportunities.json`，保存机会、起意阈值、暂存念头、模型尝试预算和投递去重。损坏或未知版本不会自动覆盖。
- 持久投递意图保留原文及操作标识。收到回执后先确认机会状态，再清理意图；确认写入失败可沿同一意图恢复。部分投递和未知回执进入待复核状态，不自动生成替代消息。未留下投递意图的孤立选择在重启或十分钟后转为暂存。
- 私人原话、个人建议和暂存念头按会话范围过滤，生成中切换渠道或关闭插件分享也会重新检查。群聊与插件代理不注入私人生活上下文。
- 普通聊天可按相关性读取暂存念头；读取不会推进机会、消耗随机数或调用模型。

备份请停止应用后保存整个用户数据目录，特别是世界 JSON、原件备份、历史 SQLite 及存在的 WAL/SHM、生活队列、机会文件、主动状态与图片。完整操作说明见[用户指南](../user-guide/amphoreus-world.md)。

## 验收结果

环境：Windows、Node.js 24.16.0、仓库固定 pnpm 10.33.0。相关回归共 **37 个文件、435 项测试通过**，覆盖机会衰减、轮询频率、重启恢复、投递失败、取消、会话范围、设置兼容、世界迁移、长期推进和界面。

主进程、预加载、渲染端、服务器四套 TypeScript 检查通过。桌面主进程、服务器和渲染端构建通过；字体与 Web 入口预算检查通过，入口依赖共 222843 字节。构建造成的已跟踪静态资源换行差异经比对后恢复，编译产物保留在本地。

### 固定种子节奏演练

脚本 `scripts/verify/proactive-rhythm.mjs` 使用实际机会库、策略与持久投递服务，来源和模型使用隔离 fixture。三个固定种子为 `7`、`42`、`20261117`。为观察高密度，演练显式采用每日 20 条上限，**不是修改用户设置，也不是实际发送次数承诺**。

| 同一组丰富内容场景 | 安静 | 自然 | 活跃 |
| --- | ---: | ---: | ---: |
| 三个种子总发送数 | 38 | 49 | 51 |
| 各种子单日发送数 | 11 / 10 / 17 | 15 / 14 / 20 | 17 / 14 / 20 |

活跃档的各组开场间隔分别为 6–125、15–141、9–98 分钟；48 个间隔中，29–31 分钟占 2.08%。这用于检查没有半小时聚集，不能据此预测真实聊天频率。

八组契约断言通过：同种子完整轨迹可重放；日/小时/问题上限；连续三日不回复最多两次开场；无新内容时第 29/30/31 分钟均无机会、无模型调用；离线不累计压力；重启不重抽阈值；恢复无即时补发突发；丰富场景的间隔不集中在半小时。

正式十八组场景共 180 次 fixture 模型函数调用，完整重放另有 63 次，合计 243 次；真实模型 API 请求为 0。报告位于 `.build-temp/proactive-rhythm-verification.json`，轨迹 SHA-256 为 `cda55415324712aa30e3a8f41391709974209dd3034534bc7366d8f1956c367c`，报告另存源码及运行 bundle 的摘要。

## 仍需区分的边界

本轮完成源码与本地构建，没有发布安装包、部署 Linux 服务或重启用户现有实例；运行中的旧实例需要重新加载新构建。没有真实模型剧情质量、真实渠道外发或长时间真人使用验收，亦未运行整个仓库的全部无关测试。

个人生活中的轻量活动有本地规则生成部分，复杂剧情仍由既有世界模型规划与结算产生。`addPersonalIntention` 已具备带会话范围的存储与去重能力，尚未暴露为聊天工具，不能声称任意聊天请求都已自动转化为个人行动。共同兴趣联想目前依据真实文本和保守关键词关联；“无需回复”的表达由模型协议与提示约束，实际文风仍需后续使用反馈。

本轮没有新增官方剧情考据。世界发展仍属于项目明确标注的战后延续世界线。
