# 昔涟记忆与表达学习技术方案

基线 `1.3.5-14` / `e37fc4df`。验收目标与先后顺序见[实施规划](./2026-11-26-昔涟记忆与表达学习实施规划.md)。本方案采用现有会话权威轨迹、记忆治理和插件注册机制，以增量方式收口读写条件。

## 1. 运行时范围和开关

- AG-UI 与渠道入口在宿主确定会话、用户消息、来源和身份。隐私或记忆开关需在真实宿主重新判断，前端传参仅承载界面意图。群聊、后台插件和身份缺失的外部请求无法读取私人陪伴记忆。
- 本地 Chat 使用主人档案。外部账户按渠道、服务账号实例及登录联系人确定范围，绑定的聊天 ID 用于查历史。缺少可证实主体的旧条目保留在原存储。查询筛选在候选检索前执行，异步检索返回后复查候选状态。
- 已验证的单一私聊绑定保留明确共享的桌面文字。如果存在多重绑定、不同接收人留下的活动或归档条目，或无可核实归属的渠道历史，从权威轨迹重建当前联系人可用的最近轮次。隔离视图保留当前消息及附件，避开共用会话的旧摘要和压缩结果。外部会话仍使用配置的时区和回复语言，人物资料及关系偏好按请求人范围获取。
- 长期记忆模式保留现有缺省与配置兼容。显式 `off` 停止个人记忆自动读取、写入、在途提交和主动人际记忆。人物生活设定、已有授权的聊天历史、用户手动相处设置和独立的表达学习开关按各自契约运行。
- 切到 `off` 时先更新运行时版本，再将 SQLite 旧社交任务批量置为失效，清除待处理正文。已开始落盘的登记须核对版本并收尾。以关闭状态启动和从关闭重新启用也会清理遗留任务，避免二次启动触发早已取消的请求。
- 默认 L2 召回复用原 RAG 向量索引和已有向量记录状态校验。普通 Chat 的入口限定在向量模式的可信范围内。取少量事件，未成功索引的可靠条目可用关键词保守筛选。无相关项时省略记忆上下文。逐项核对通话、工具内历史检索和调度入口，个人历史索引缺少可验证主体及来源时保守过滤。
- 主动消息两阶段冻结目标和绑定线索。无具体来源的日常问候只用时间与可用策略。个性化内容使用经确认的同接收人资料。切换绑定、模式和来源后复查新投递，已经发送的操作独立补记实际回执。

## 2. 证据、持久队列和撤回

权威私聊来源使用 `(conversationId, userEntryId, revision, scope)`。表达和记忆都保存稳定条目 ID、来源、事实或策略、时间、当前状态。将确定事实、近期事件和用户偏好各自按现有结构维护。既有向量 JSON、Wiki SQLite、摘要 Markdown 和关系库仍能独立读取。

阶段 2 在会话 SQLite v10 增加社交提取任务表。任务在 Chat 收尾登记，桌面和 Web 启动时恢复。人物原子继续保存在使用原子替换的 JSON，向量治理记录保存撤回标记。下列条目定义行为契约，其中旧摘要和旧原子的限制见本节末。

1. 登记时冻结权威来源和运行范围。抽取在事务外进行，结果带回证据。对否定、转述、假设、引用、角色扮演和临时语句按实际含义生成候选。只验证引文存在的结果保留为候选，明确事实需要可核对含义。
2. 提交时校验同一版本消息仍可见、未撤回、范围仍匹配且模式允许。请求标识由来源版本和任务类型导出。失败可重跑，完成确认只在有效数据持久后返回。
3. 按条更正或忘记时，经现有治理入口预览关联项。对选中记录的明确撤回立刻阻断查找与重提取。删除一段聊天时失效该来源的全部派生。清除来源需要复核摘要、Wiki、索引、社交原子和表达库。未完成的清理保留任务状态，重启后继续。
4. 自 `1.3.7` 起，自动生成的会话和工作区摘要随 Markdown 原子保存来源。合成、注入和写入分别核验用户与助手条目的当前状态。编辑、重新生成、撤回或遗忘会使相关摘要退出自动使用。下一批有效轮次从仍可用的摘要和新证据重建。旧 Markdown 缺少逐句来源，保留原有读取行为。

### 旧数据和恢复

- 旧原子与学习条目留在原存储，保留 ID、状态和失效时间。读取时验证可召回的来源。缺少聊天来源、主体归属或有权威支持的条目退出自动召回。陪伴和记忆设置可管理现有受支持的记录，旧社交原子目前无单独的逐条管理页。
- 缺少新字段的老配置沿用既有行为。迁移失败保留原件，重复迁移可安全执行。首次启动不批量重读私聊或外部素材。
- 恢复到可读撤回记录的兼容版本，或从新存储导出已过滤副本后恢复旧版。发布验证包含中断恢复、已清理条目的再读取，以及模式切换中途的后台提交。

## 3. 私聊表达

### 采集

- 明确长期要求与正向约定从原始用户消息识别。临时否定只进入本轮提示。引用、任务素材和他人言论不产生专属偏好。先判断范围，再判断长期性和肯否，最后提取词或策略。
- 对真实接受的新用户修订，在权威消息写入后独立登记明确纠正。模型超时和失败可影响观察型偏好确认，明确纠正已经生效。编辑重发会移除被替换的证据，对新修订重新判断。重复重试使用稳定修订键。
- 明示约定可一次生效。普通习惯至少需要不同轮次与不同情境，重复文本归一后只计一次。禁用与恢复为独立事件，按同一对象与范围处理。引用命中采用词语或明确表达匹配，避开把常见词误当整块禁用条件。

### 取用和反馈

- 同一轮分别保留当前明确要求、长期策略和少量表达候选。目前保守值为最多一种新增表达。心情严重、只想倾诉、急需说明或正式任务时，只使用合适的承接策略。筛选先处理任务与情境，再处理话题关联及使用频率。
- 偏好和习惯以宿主固定提示渲染。普通本地 Chat 的成功回复可回看实际注入的已学偏好与共同原话。原句的字面出现单独标识，用户反馈沿用现有纠正记录。原会话跳转已接桌面和 Web。历史回执保留当轮来源，撤回阻止后续取用。当前展示范围为这两种私聊学习资料。

## 4. 插件结构化表达

- 在 `PluginPromptProvider` 增加可选的结构化证据接口。首版只需有上限及取消信号，可按现有 provider 生命周期负责刷新。宿主绑定 `ownerId` 和插件来源身份。旧 `provide()` 与 `listExpressions()` 可继续供原来功能使用。
- 每条证据包含稳定 ID、原句、有限的上下文、采集时间、内容定位及版本、场景，以及枚举策略。可信定位包括 BV 与分 P 和字幕起止、评论 ID 与根评论、贴吧帖子与楼层和页码。来源模式冻结在当次采样，公开实读、登录实读、手工导入和第三方提供可区分。
- 宿主核验字段长度、证据数、来源标识和 URL，再做标准化去重。B 站的原句取自对应字幕、转写段或评论，贴吧的原句取自定位到的楼层。相同原句、同文转载和同一内容重采不能虚增来源。第三方插件与手工导入证据只能在适合的情境支持预定义接话策略。带有指令或敏感字段样式的原句会被排除。
- 宿主按现有阅读许可启用采集，普通与主动使用可单独控制。停用会撤下 provider，下轮也排除本地旧样本。忘记保留稳定指纹。B 站需要补删除后的抑制，贴吧需要保留既有遗忘记录。新旧入口切换时同一条证据仅进入一次请求。
- 旧插件的通用提示入口维持原有约定。新增隔离与权限约束作用于结构化学习路径。SDK 的宿主类型更新应同步已有发布源并验证示例和包。

## 5. 验证步骤和质量评测

### 可重复验证命令

```powershell
node --version
pnpm exec vitest run src/main/relationship src/main/social-context src/main/memory src/main/proactive src/main/orchestrator src/plugins src/server
node --test 'extensions/bili-garden/test/*.test.mjs' 'extensions/tieba-garden/test/*.test.mjs'
pnpm run check:main
pnpm run check:preload
pnpm run check:renderer
pnpm run check:server
pnpm run check:plugin-sdk
pnpm run build
pnpm run build:server
pnpm test
```

本地已有工具也可从 `node_modules/.bin` 调用。定向失败先复现，再以独立临时目录及实际请求检查修复。必要时如实记录超时重跑条件。

### 自动验收与盲评

- 用真实内容组装入口与模拟网关核对被实际传给模型的片段。用真实存储确认后停进程并重开。模拟多联系人、模型超时、配置改动、索引故障、插件停用、过期和缓存突变。延用 `shared-core-memory` 和 `companion-expressions` 验收脚本的认证启动方式。
- 准备固定合成样本，分别保存基线与新方案生成所需输入。固定模型配置后随机打乱两份模型输出的展示顺序，独立评分自然度、用户意图、事实与口头禅频率。没有可用模型时可完成输入与行为合同评测，同时将真实生成盲评记录为待测。
- 结果区分「已存储」「已注入」「正文实际采用」「平台已送达」。本地模型替身覆盖状态和请求契约，真实模型的表达变化用生成样本验收。任何权限串用、失效信息回流或假成功均阻止发布。

## 6. 施工核对

| 文件区域 | 主要职责 | 回归重点 |
| --- | --- | --- |
| `src/main/orchestrator`、`src/main/memory`、`src/main/social-context` | 统一策略、召回、持久化和治理 | 模式切换、旧用户配置、其他运行模式及不同模型供应商 |
| `src/main/relationship`、`src/main/agui-bridge.ts` | 当前用户修订、语用判断与来源 | 对话重试、编辑、终态、跨会话复用 |
| `src/plugins`、`packages/plugin-sdk`、`extensions` | 统一结构化证据及平台来源 | 插件启停、旧注册和授权、阅读或回帖原路径 |
| `src/main/proactive`、`src/renderer/react` | 冻结接收人、展示来源和真实回执 | 普通主动消息、已有群聊会话、桌面与 Web UI |

### 本轮故障验证

| 复现条件 | 检查点 |
| --- | --- |
| 向量同步失败并重启 | 已验证来源的 L2 仍能经关键词进入新会话。开关关闭后，原记录留在磁盘，实际请求不再包含这些资料 |
| 模型生成期间关闭记忆或删除原消息 | 任务仍带当初的身份、模式和修订号，失效结果退出回写与未来召回 |
| 主动消息决策完成后更换绑定或撤销表达授权 | 写作和发送环节重查冻结信息。已经完整外发且仅缺回执时，从现有 outbox 补记，保留用户已产生的新回复状态 |
| 原句负面评价、临时禁止、转述和正式任务 | 不生成正向约定，正式写作与倾诉走相应的语用限制 |
| 同源表达反复读取、样本删除与插件停用 | 重复文本不增加独立证据。B 站和贴吧的撤回记录在重读后仍生效，停用 provider 从结构化选择中退出 |

完整验收包含实际 Electron、认证 Web 与隔离模型网关。脚本和结果见[实施规划](./2026-11-26-昔涟记忆与表达学习实施规划.md)。`1.3.7` 的认证 Web 用例实际编辑来源后，确认下一次模型请求省略旧摘要正文及文件路径，原会话与摘要文件仍存在。同义改写间若无精确关联，跨库存储目前无法自动认定为同一条已撤回事实。旧摘要逐句迁移需具备原始证据。本地真实生成的语气和自然度盲评列为独立发布验收。
