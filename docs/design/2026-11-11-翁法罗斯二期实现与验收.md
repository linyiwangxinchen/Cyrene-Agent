# 翁法罗斯二期实现与验收

2026-11-11。实施前的契约见[二期实施设计](2026-11-10-翁法罗斯二期实施设计.md)，问题依据见[完整性复审](2026-11-10-翁法罗斯完整性复审与二期方案.md)，使用与备份步骤见[用户指南](../user-guide/amphoreus-world.md)。

## 本轮落地

| 原问题 | 实现后的行为 |
| --- | --- |
| 人物主要是资料卡和固定作息 | 21 位居民分别保存精力、目标、当前关注、经历和关系变化。三子拥有不同人物 ID，共享一个黄金裔席位。差异作息、目标状态及休息需求影响日常活动。 |
| 每日计划预写所有结果 | 模型先提出意图和前提，事件到期后根据当时状态结算。支持部分完成、失败、取消和延期；前序失败、物资和通行限制会影响后续。 |
| 城邦只有介绍 | 十处地点具有通行、设施、供给状态。模拟通路包含双向耗时，受限与封闭会约束出行；日程为往返预留时间。 |
| 事件只留下文本 | 经过校验的结果可以改变地点、个人目标、居民关系和公共事务；事件版本及世界修订检查防止迟到或重复应用。 |
| 未结事务被窗口截掉 | 未结事务持续保留，更新时保留此前参与者；短期读取窗口与长期历史分离。 |
| 普通主动消息缺少世界状态 | 普通聊天、各主动场景和生活自拍使用同一生活投影，精力来源统一，最近完成内容使用实际结果。 |
| 观察页信息直接成为角色知识 | 分别记录亲历、听闻和日常。公开结果至少两小时后，在适合交流的作息中传播；私人事件不全局传播，旧消息不会因短期记忆压缩重复变成新消息。 |
| 跨时区、停机和过期租约断层 | 保留已发生历史，调整未开始日程、中断进行中活动，保护新时区的食宿；记录离线区间；先收敛过期租约再判断重试额度。 |
| 长期历史不可追溯 | SQLite 编年史保存事件及因果、个人经历、事务版本和离线记录，支持人物、地点、时间游标分页。完整 JSON 先提交，成功归档后才裁剪短期快照。 |
| 页面难以观察变化 | 增加城邦示意图、居民目标与经历、事件缘由与后续、编年史、上次离开后的变化，以及按需作品预览。 |

新增代码集中在 `src/main/amphoreus-world/`，共享契约与资料在 `src/shared/amphoreus-*.ts`，页面在 `src/renderer/react/features/settings/Amphoreus*`。Electron 和 Web 共用服务、存储及 IPC 处理器。

## 运行边界

- 每日最多一份成功计划，每份 3–8 件事件，至少覆盖 6 位居民、2 个地点和一位 NPC，昔涟最多参与一件。超过七天未得到公共经历的人物会进入必须考虑的轮换名单；新计划同时检查昨日延期到今天的约定。
- 默认每日最多 8 次模型请求，规划、批量结算和重大结果审核共用额度。单任务最多 3 次尝试、失败退避 30 分钟、流程 90 秒超时；现有模型适配调用设置单次输出上限 6000 tokens。普通作息不请求模型。
- 身份、火种、官方历史不在模型可修改字段内。已知明确文本冲突被拒绝；重大事件或通行变化需要另一轮带事实引用的审核。自然语言一致性检查和模型自审并不构成完整的剧情正确性证明。
- 每次结果只能更新本事件地点及参与者的已知目标/关系，不能靠重复效果绕过增量上限。取消事件不会留下成功影响或被记为实际参与经历。
- 原涟界文件保留；世界 schema 1 首次升级额外备份原件。已完成事件和绑定 ID 保留，旧版未来结果被丢弃。未来未知版本拒绝覆盖。
- 快照保留最近 60 天及仍未结束的日计划、每人最近 48 段短期记忆；更早世界记录可从编年史读取。恢复归档失败后可幂等重放。原个人兼容时间线/日记仍有 2000 条窗口，原涟界文件作为旧档继续保留。

## Web 与资源开销

翁法罗斯页面继续按需加载。地图为 SVG 与原生按钮，没有地图 SDK 或三维资源。隐藏页面停止轮询，历史默认每次 30 条；图片点击后才加载，按作品 ID 校验路径、格式和 8 MiB 大小上限。

刷新携带内容摘要标识。摘要覆盖实际活动、生成状态、资料与作品等字段，时钟单独返回；不能只依赖世界修订号，否则非昔涟居民的活动切换可能漏报。内容不变时不重传整个视图。

生产 Web 入口依赖共 7 个文件、222843 字节，与上一轮预算相同。人物详情、编年史、地图和图片预览未进入入口依赖。构建仍有项目既有的大分块提示，不能据此声称整个应用的全部页面都已完成性能优化。

## 已执行验证

环境：Windows、Node.js 24.16.0、pnpm 10.33.0；所有运行测试使用隔离临时目录，外部渠道关闭。

1. **14 个文件、151 项相关测试通过**。覆盖旧档迁移、原件备份、未知版本、读写失败、归档故障恢复、重复应用、文本与结构边界、独立认知、预算/超时/取消/租约、时区、跨日冲突、个人历史筛选及异步响应顺序等。
2. **连续 90 天压缩演练通过**：每周重新创建存储实例；全体居民获得经历，目标持续推进；快照维持 60 天，首日公共事件仍能从归档找回，分页没有重复或缺口。
3. 主进程、preload、renderer、server 类型检查通过；服务端共享核心与 Web 生产构建通过；字体及 Web 入口预算检查通过。
4. `node scripts/verify/amphoreus-world.mjs --ui` **四组集成检查通过**：真实编译后的 Web 服务与共享核心完成一次规划及一次结算，共两次测试模型请求；认证、重启、开关、历史分页、作品边界正常；桌面 1366×960 与手机 390×844 正常展示 21 位居民和十处地点，个人历史及图片实际解码通过，无页面脚本错误和面板横向溢出。
5. 浏览器模拟 **250 ms 延迟、256 KiB/s 下载、128 KiB/s 上传**时刷新成功；未变化的响应小于 500 字节。这是模拟弱网刷新检查，不是线上 CF Tunnel 的实测延迟。

## 仍然简化的范围

本轮完成了持续状态、因果结果和观察入口的主要链路；没有宣称完整复刻游戏所有支线、组织及未公开设定。当前环境采用粗粒度供给和通路，消息采用带延迟的公共公告；尚没有完整经济、逐段道路施工、人物间逐条转述网络或模型生成的长期章节摘要。人物新增日常偏好、目标方向和行程参数明确属于项目延续假设。后续扩充应继续保留事实来源、原始事件引用和上述验证边界。
