# 翁法罗斯：资料基线与世界模拟设计

日期：2026-11-10。适用：Windows 桌面、Linux/Web 共享核心。开发顺序：资料核对 → 本文 → 世界内核 → 运行接入 → 一级页面 → 回归测试。

## 1. 目标与时间线选择

“涟界”更名为“翁法罗斯”。世界有独立居民、公共事务和历史，昔涟是其中一位居民。聊天、打开页面和主动陪伴开关均不是世界运转的前提。现实时间决定日期、昼夜与作息；大模型每天决定公共事件如何延续。

需求中的“铁幕”按官方名称“铁墓 / Irontomb”处理，时间锚点为 3.7 决战后。必须区分：

1. **官方历史**：逐火、轮回、对抗铁墓以及记忆的保存，构成不可由每日模型改写的历史。
2. **本项目延续**：以保存下来的世界记忆为起点，让居民重新拥有可以继续的日常。十二黄金裔与昔涟共同活动、城邦日常恢复，是本项目的战后延续假设，不宣称官方已经确认所有人同时复活或全部城市重建完成。

“一页永恒”不是普通档案馆；丹恒不是哀丽秘榭原住民；长夜月不能被写成与三月七毫无关系的普通市民；昔涟不能凭空多占一枚“真我火种”。这些约束进入模型输入和资料卡。没有可靠来源的命运结论不填为官方事实。

## 3. 历史与设定约束

| 阶段 | 历史主干 | 每日模拟约束 |
| --- | --- | --- |
| 逐火世界 | 城邦、黑潮、泰坦、黄金裔与火种 | 不能将所有人改成现代办公室职员 |
| 逐火旅程 | 各人使命不同，普通居民也有生活 | 独立目标，不由昔涟给所有人派任务 |
| 轮回真相 | 权杖演算与毁灭实验；白厄和昔涟反抗终点 | 不把重启轮回作为每天默认剧情 |
| 铁墓决战 | 列车与多方力量参与 | 不每日重新击败铁墓或触发灭世 |
| 战后记忆 | 《如我所书》与一页永恒承接记忆 | 不编造官方重生日期与全员存活证明 |
| 项目现在 | 战后记忆延续的共同生活，接入现实日期 | 日程和事件明确标记为模拟续写 |

十二火种：浪漫、门径、纷争、死亡、理性、诡计、天空、海洋、律法、岁月、大地、负世。它们不是每天可以转让的任务奖励。模型不能修改角色资料、姓名、火种和历史身份。

本轮覆盖运行所需剧情主干、十二席、昔涟、常见城邦 NPC 与地点，并非穷尽游戏全部隐藏任务和对白。未核实细节不进入事实表，模型也不能将补写升级为官方设定。

## 5. 地点与公共事务

地点：奥赫玛、悬锋城、雅努萨波利斯、神悟树庭、哀丽秘榭、斯缇科西亚、哀地里亚、黎明云崖、昏光庭院、一页永恒。出身不等于当前位置；历史毁损地点可作为记忆场景，不宣称现实宇宙已重建。

公共事务保存 `id/title/summary/nextStep/participants/status/updatedAt`。日常物资、知识保存、往来通路等从明确标记的项目初始设定开始，由已结束事件更新。模型可延续、转向、解决事务；不能每天重置已解决问题。未落实计划与已发生结果分开。

## 6. 内核与存储契约

新增 `src/main/amphoreus-world`，共享契约 `amphoreus-world.ts`，版本化资料 `amphoreus-canon.ts`。

`amphoreus-world.json` version 3 包含公共事务、每日计划、推进尝试、已应用事件，以及昔涟个人时间线/日记/生成物兼容投影。复制迁移 `xilian-world.json` 并保留原件；旧 ID 不改写。旧架空地点只用于历史，新日程不得回到序页城、星炉台、岚栖等旧设定。

已有新文件不重复迁移；损坏旧档备份后处理，不能吞掉备份失败；未知未来版本拒绝覆盖。同目录临时文件原子替换，一个进程共享 store；异步生成提交时重读最新数据，保留期间的自拍/日记修改。每日计划最多保留 60 天，个人事件最多 2000 条，持续事务保留最新结果；旧文件提供历史追溯。

兼容 `companion.getWorld()` 原字段，增加 `amphoreus` 投影。密钥、聊天原文、绝对路径不进入世界视图。模型只返回数据，界面纯文本渲染。

## 7. 时钟与作息

- IANA 时区 + Unix 时间；无效时区回退 UTC，展示实际采用值。
- 睡眠 23:00–07:00，早餐 07:00–08:00，上午通勤 08:00–08:30，午餐 12:00–13:00，午间休息 13:00–13:30，晚餐 18:00–19:00，睡前休息 22:00–23:00；其余按居民身份活动。
- 公共事件不得覆盖睡眠/餐食；同一居民不能重叠或在同日公共安排中无过渡地换城。
- planned → active → completed 随时间计算；未来结果不展示、不注入聊天、不提前写日记。已完成事件不因时钟倒退撤销。
- 停机不逐分钟补造生活，恢复后仅接续今日；不在启动时追发数十次模型请求。
- 每分钟对账，但只在时段、事件完成、计划和配置变化时写盘。

## 8. 每日模型推进与失败路径

后台与主动聊天独立，桌面和 Linux 共享核心启动时挂接，退出清理 timer/AbortController。无需页面常开；服务停机时无法实时调用模型。

复用默认模型与统一 LLM client，无工具权限、无需新增密钥。输入：资料约束、现实时间、轮换居民、已完成事件和公共事务，不包含聊天、关系档案或设备数据。

模型返回有界 JSON：日期和事件，含开始分钟、持续时间、地点、居民 ID、活动、影响等级、计划摘要、完成结果及事务进展。拒绝未知 ID、越界/重叠时间、群像配额不足、超长/损坏 JSON，整体失败不部分采纳。本地作息来源始终为 routine。

每个日期最多一个成功计划；生成前保存租约/次数，并发刷新不重复请求。重启保留退避；每天最多 3 次尝试，失败间隔 30 分钟；无配置显示等待配置。跨午夜、切换时区、停止或禁用后，迟到结果作废。错误只显示固定分类，不泄漏供应商原文。

用户可单独关闭每日模型推进，现实作息继续；重新开启按剩余额度恢复。网络失败明确显示本地作息与失败类型，不假装已成功续写。

## 9. 页面与聊天

一级“翁法罗斯”与“昔涟设置”并列，支持路由和搜索；按需加载，页面可见时一分钟刷新，后台停止轮询，返回立即刷新。不在首页预载资料、不由页面直接调用模型。

展示世界时钟、推进状态/开关、今日与近期事件、重大事件筛选、公共事务、全部居民状态、人物资料来源、地点、昔涟居民日程和旧日记。提供加载、空态、错误重试，适配移动端与键盘。

聊天/自拍读取同一状态：公共背景有限注入，只有昔涟参与的事件才成为她的经历，未来计划不能说成已经完成。睡眠不声称刚巡逻完，世界经历不成为用户关系事实。当前时间线约束覆盖旧世界书中可能冲突的“仍在逐火”情境。
