# 同一个昔涟：设计修订与开发路线

## 对原方案的修正

陪伴、恋爱表达、办事、写代码和学习都是昔涟的行为，不是两个身份，也不新建“女友模式”。Chat / Work / Code / Learn 继续表示任务编排；切换它们不得丢失人格、称呼、关系边界和记忆。保留现有 soul 的活泼与温柔，不把她改成通用的安静客服。

关系设置只影响相处方式，不能授权工具。助手能力不能因为关系较疏远而被移除。权限档位是操作范围，不叫“关系权限”。保留原有权限、CTA、Harness、记忆引擎、渠道和插件实现，避免创建平行的聊天系统。

## 实施顺序与验收

1. **统一身份**：版本化人格及角色包；四个模式、通话、主动消息共用契约。用提示词组合测试验证，保留原有角色和工具职责。
2. **关系与情绪**：持久化版本、用户可调相处程度/称呼/语气/共同目标/时刻/边界；暂停、修复、重置、导出。事件幂等，情绪随时间回归基线；聊天次数和离开时间不奖惩关系。旧关系日志迁移并校验，损坏数据报错而非覆盖。
3. **真实上下文与渠道隔离**：设置进入正式共享核心的上下文；互动线索按 conversationId 读取，群聊不能读取个人关系记录；绑定到同一会话的微信自然共享该会话的线索。保留 CTA 来源引用、派生线索及原有关系日志短文本片段，不建立第二份完整聊天记录。
4. **Windows / Web 管理界面**：在昔涟设置中加入统一人格、关系、情绪与记录管理；同一 typed IPC/preload 经认证后的 Web core transport 使用，不另造仅旧服务器可用的 API。版本冲突提示重新加载；手机可操作。
5. **主动与叙事**：关系暂停立即阻止主动生成及发送；主动消息使用相同边界/目标，沿用已有 DND、渠道冻结、未回复退避和评分解释。可选、默认关闭的角色小记明确标记虚构，低频生成，不伪造传感器事实。
6. **权限与隐私**：复用已有工具风险、目录沙箱、审批和副作用账本；提供额外可撤回的能力限制与暂停控制，不能靠提示词冒充权限检查。关系记录独立可暂停/删除/导出，明确与原始会话、L0/L1/L2、Wiki、摘要的区别。既有记忆中心负责这些原有记忆的编辑管理。
7. **验证交付**：迁移/重启、冲突、删除不复活、连续事件、时间衰减、群聊隔离、正式 headless IPC、Web UI、Windows 编译和 Web 构建；逐项记录结果。100 次状态模拟不等同于 100 轮真实模型人格测评。

## 数据与兼容策略

- 人格和角色包是版本化代码；角色资产引用现有资源，遵守现有 LICENSES，Web 不要求 Live2D 或 Linux GUI。
- 关系日志是 CTA 的派生视图，来源保留 conversationId/runId/eventId；不另建事实权威。旧无来源线索只供用户查看，不跨会话注入。
- 持久化关系状态及审计使用 SQLite 事务，首次读取迁移旧 JSON。设置使用独立 revision，普通对话不能导致正在编辑的设置无故冲突。
- 用户明确配置的称呼/边界属于全局个人偏好；群聊不注入。自动识别的情绪只是线索，不是诊断，不写成用户事实。
- 密钥不进入新数据库、日志或导出；删除关系记录不冒称删除了聊天原文和用户自行保存的备份。
- 插件目前仍为可信宿主代码。权限策略能约束经 Harness 的工具调用，不能把同进程插件称为 OS 沙箱；强隔离需要单独兼容迁移，不能在本次静默破坏现有插件。

## 不机械套用的建议

原文件是多阶段建议，其中新建第二套聊天/CTA、角色改名、强制替换所有记忆存储、重新拆四个进程、把所有插件立即搬出进程均不是本次的前提。沿用已有实现，通过统一人格和可管理状态完成实际体验；语音硬件和第三方服务以可用环境验收，不能在没有设备或凭证时宣称验证通过。

## 原方案与实现映射

| 领域 | 实现 |
| --- | --- |
| Persona / CharacterPack | 唯一人格契约、版本化角色包；保留 soul 和既有素材 |
| Relationship / Emotion | 状态管理、SQLite 迁移、修复/暂停/重置、衰减与本地表情映射；不根据弱推断升级关系 |
| Memory | 扩展原记忆中心的来源、修正、归档、级联摘要删除和导出；保留 Wiki/向量/摘要引擎 |
| Inner Life / Life Event | 默认关闭的明确虚构小记、显式目标与日期候选；精确提醒复用 scheduler，不虚构进度 |
| Assistant / CTA | 复用 Harness、Skills、插件、子代理、试卷、工具轨迹、执行账本与 CTA；四模式同一身份 |
| Permission | 独立能力档、逐工具禁用/确认、暂停与审批后撤回；复用目录、渠道和风险检查 |
| 主动陪伴 | 新候选加入已有评分、冷却、未回复退避、勿扰、渠道路由；发送前检查设置版本 |
| 多模态与语音 | 复用 ASR/TTS/通话/图像与文件链路；新增通话人格与本地表情接入，不声称支持所有 TTS 韵律参数 |
| 多端管理 | typed IPC/preload；认证 Web 经 core transport 共用实现；设置面板适配窄屏 |
| 安全 / 隐私 | 复用认证与 CSRF，新命令校验、版本冲突检测；关系记录可停用/删除/导出 |
| 评测 | 迁移、幂等、来源隔离、权限撤回、记忆级联和失败路径测试；正式 headless 与浏览器验收 |

独立插件进程/OS 沙箱、全局 KeyVault 迁移、全链路备份删除、数月真实用户评测、所有语音硬件兼容性和重新制作角色动作资产未包含在这次实现中。它们需要独立迁移设计或设备/服务验证，不能用配置开关冒充完成。
