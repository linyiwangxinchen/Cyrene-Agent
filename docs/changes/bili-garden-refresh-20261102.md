# 小花园“一起看”频繁刷新修复（2026-11-02）

插件版本更新为 `0.1.2`。

## 原因

面板每四秒读取一次后台快照，原实现随后无条件执行 `replaceChildren` 重建页面。即使待看列表没有变化，也会重新创建输入框和视频卡片。真实认证 Web 回归已复现：等待两次轮询后，原输入框从 DOM 中脱离，未完成的输入和焦点丢失。

## 修改

- `panel.js`：按当前页实际使用的数据判断是否需要更新，后台任务进度或其他页面的数据变化不会触发“一起看”重建。
- 待看表单保持原位，视频卡片按 BV 号复用，只增删或替换实际变化的卡片；未变化的封面节点也保留。
- 保存本次面板中的输入草稿；提交成功后只清除本次提交的文本，保留请求期间输入的下一条链接。
- 并发快照请求合并处理；提交期间已经有轮询在进行时，完成后再读取一次最新快照。
- 状态栏和安装日志在内容变化时更新；设置草稿仍受保护，重复点击当前标签不清空修改，“放弃修改”明确恢复保存值。
- `manifest.json`、`README.md`：更新插件版本和行为说明。

## 验证

- `node --test extensions/bili-garden/test/*.test.mjs`：37 项通过，包括输入、光标、卡片复用、提交与轮询并发、设置草稿及放弃修改回归。
- `pnpm run build:web`：通过，已确认产物 `dist/plugins/bili-garden` 包含 0.1.2 修复。正式运行端加载该打包副本，不能只改源目录就认为已生效。
- `scripts/verify/bili-garden-web.mjs`：正式编译的共享核心与认证 Web 面板验收通过。检查了两次真实四秒轮询后输入框仍为同一节点、选区与焦点保留、另一个客户端加入视频时表单保留、未变化卡片复用，以及手机端输入和滚动位置稳定。
- 浏览器没有页面脚本错误，已查看手机截图。构建资源的纯换行改动已核验并恢复，不提交生成产物。

本次没有访问远端生产服务，也没有操作真实 B 站账号。更新源码后重新执行 Web 构建并重启服务，再刷新浏览器加载 0.1.2；无需重新安装 Python 或转写模型。
