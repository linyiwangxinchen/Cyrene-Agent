# 小花园转写依赖安装修复（2026-11-01）

## 问题和原因

用户收到阿里云 pip 索引下 `faster-whisper` 的 `No matching distribution found`。代码检查发现基础依赖安装会传入 `CYRENE_BILI_PIP_INDEX`，而转写阶段另起一条 pip 命令，漏掉该参数，继承了系统配置。该缺口可以使两个阶段访问不同索引。原流程还缺少解释器诊断和镜像失败后的有限重试。

本次核对时阿里云索引能返回 faster-whisper 的软件包列表；官方 PyPI 也提供该包，因此仅凭原错误无法证明服务器当时的镜像缺包或确定网络原因。修复统一了可控的安装链路，并保留失败原因供运行端诊断。

## 修改

- 基础与转写安装共用安装函数。按插件环境变量、PIP_INDEX_URL、官方 PyPI 的顺序选源；隔离全局/用户 pip 配置及额外索引，避免配置悄然覆盖，不修改宿主机全局配置。
- 镜像解析或连接失败时重试一次官方源；取消、停用和非网络类错误不重试。不混合多个软件源。
- 打印 Python 版本、操作系统、架构和位数，拒绝过低版本与 32 位转写环境。
- 去掉手工添加的旧版 PyAV 上限，交由 faster-whisper 的依赖声明解析；原生依赖只使用 wheel，避免服务器意外进入大型源码编译。
- 安装包后先验证导入，再单独下载和加载模型，成功后才记录就绪。安装期间切换模型也不会把旧模型标成新模型就绪。
- Windows/Linux 共用该流程。说明和可复现的临时环境验收脚本随源码提供。

## 验证

- 24 项 Node 插件测试通过，包括 6 项新增安装回归：统一源、镜像回退、双源失败、取消、权限错误、模型切换。
- Main/Server 编译通过。
- 真实 pip 配置隔离检查通过：全局/用户配置与继承的 index、extra-index、no-index 均未影响隔离命令。
- 全新 Windows x64 / Python 3.11.7 临时环境真实安装及导入通过：faster-whisper 1.2.1、CTranslate2 4.8.4、PyAV 18.1.0、yt-dlp 2026.10.26；pip check 无依赖冲突。真实宿主 Agent 与 ZIP 导入回归通过。
- 此轮未访问用户服务器；模型权重下载与实际音频识别不属于此次软件包安装验证。
